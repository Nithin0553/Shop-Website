These six starter blog thumbnails use remotely hosted editorial photographs selected from free-use stock photo pages. They are displayed only while an article still uses its original starter image; if an admin replaces that image, the uploaded image takes precedence. The client falls back to the bundled original thumbnail if a remote image cannot load.

Photo rights remain with their respective creators. Review each linked image's current license before using it in a different context.
